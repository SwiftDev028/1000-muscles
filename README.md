# Теодарская Пицца 1000 мускулов

Статический сайт с фитнес-рецептами (КБЖУ).
Только HTML, CSS и JavaScript в одном файле, без сборки, сервера и базы данных.

## Публикация на GitHub Pages
1. Загрузите файлы из этой папки в корень репозитория.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Шрифты Barlow подключаются из Google Fonts, поэтому нужен интернет. Без них сайт работает на запасных шрифтах.

## Раздел «Мой день»
Дневник питания хранит цели и записи в `localStorage` браузера (ключ `diary:v1`), сервер не нужен. Данные привязаны к устройству и браузеру. Всё хранение собрано в объекте `Store` в конце `index.html`: чтобы перейти на Supabase или другую БД, достаточно заменить его методы `load` и `save`.
